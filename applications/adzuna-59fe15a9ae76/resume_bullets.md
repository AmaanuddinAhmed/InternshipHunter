# Tailored Resume Bullets

- Built a production-ready tours and travel management system using Angular, Node. js, Express, and MySQL, taken live for real customer bookings.
- Implemented role-based access control (RBAC) with secure authentication, separating admin and end-user workflows across the platform.
- Built a full-stack trading platform across three services: marketing site, trading dashboard, and Express API using JWT-based authentication with http Only cookies.
- Added Joi-based request validation on authentication and order endpoints and deployed the full stack using Vercel, Render, and MongoDB Atlas.
