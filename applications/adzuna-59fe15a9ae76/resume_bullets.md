# Tailored Resume Bullets

- Built a production-ready tours and travel management system using Angular, Node. js, Express, and MySQL, taken live for real customer bookings.
- Implemented role-based access control (RBAC) with secure authentication, separating admin and end-user workflows across the platform.
- Built a full-stack trading platform across three services: marketing site, trading dashboard, and Express API with JWT-based authentication using http Only cookies.
- Integrated a third-party market data API through a server-side proxy with in-memory caching using Node. js and Express.
- Built a full-stack property rental platform with complete listing CRUD, Cloudinary-backed image uploads, and Passport. js authentication with session-based login.
